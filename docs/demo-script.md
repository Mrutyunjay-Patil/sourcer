with the seeded kitchen (Chai Corner Cafe, Bengaluru). Reset with the
"Reset demo" action before recording. Minimal talking, constant clicking.

| Time | On screen | Say |
| --- | --- | --- |
| 0:00 | Dashboard, empty "Requests" | "Chai Corner Cafe orders every Thursday. This is Sourcer." |
| 0:08 | Click New request. Type "20 kg paneer, 10 L sunflower oil, 5 kg tomatoes, and some eggs". Click Read items. | "I type it like a note." |
| 0:20 | Chips appear. Eggs flagged with a question. Set 5 dozen. | "OpenAI asks instead of guessing." |
| 0:30 | Reply-by set to +20 min, nudge after 0.1 h. Create. | |
| 0:38 | Request page: draft appears. Scroll the email. Edit one line. | "It drafts the RFQ in my voice. I can edit it." |
| 0:52 | Suppliers page: Find suppliers with Firecrawl. Candidates stream in. Accept one. | "Firecrawl finds wholesalers near me. I approve before any email goes out." |
| 1:10 | Back on the request. Tick three suppliers. Send. Progress strip moves to Sent. | "Each supplier gets its own AgentMail thread." |
